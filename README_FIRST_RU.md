# HiChord Pocket — Stage A

Android 10+ виртуальный инструмент: 16 голосов, восемь пресетов, PolyBLEP/FM, ADSR, SVF, chorus/delay/reverb; аккорды, ARP UP/DOWN/UP-DOWN, STRUM, DRONE и LEAD. Настоящий C++ DSP подключён через JNI и Oboe 1.8.1.

Сборка 9 ноября 2026: JDK 17, Gradle 8.6, AGP 8.3.2, Kotlin 1.9.23, SDK 34, NDK 26.1.10909125, CMake 3.22.1. Фактически прошли `testDebugUnitTest lintDebug assembleDebug assembleDebugAndroidTest`. Debug APK содержит arm64-v8a, armeabi-v7a и x86_64.

## Собрать и установить

Установите JDK 17, Android SDK 34, Build Tools 34.0.0, NDK 26.1.10909125 и CMake 3.22.1. Задайте ANDROID_HOME или sdk.dir в local.properties.

```sh
./gradlew testDebugUnitTest lintDebug assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

На Windows используйте `gradlew.bat`. Wrapper JAR включён, SHA-256 дистрибутива Gradle закреплён. APK также публикуется GitHub Actions как `HiChordPocket-StageA-debug-apk`.

## Исправления Stage A

- setup-android v4 больше не запрашивает удалённый SDK-пакет tools.
- Аудиопоток один владеет голосами, фильтрами и эффектами. JNI отправляет ограниченные команды через очередь; callback не берёт mutex и не подменяет буфер тишиной при касаниях. Переполнение переводит голоса в release.
- Повторный start идемпотентен; неудачный start закрывает поток. Восстановление после disconnect выполняется управляющим потоком при обновлении latency; stop очищает ноты и хвосты эффектов.
- Выбор голоса переиспользует ту же ноту, свободный голос, затем release-голос и самый старый удерживаемый.
- Защита входов JNI и нечисловых параметров, корректный wrap фазы, отдельная фаза саб-осциллятора PAD.
- Мультитач сохраняет последнюю удерживаемую клавишу, не перезапускает дубликаты и очищает состояния при ACTION_CANCEL/закрытии UI.
- Смена аккорда отменяет незаконченный STRUM; ARP прекращается в фоне. Меню не запускает ноты.
- Обращения перемещают отдельные голоса и меняют бас; исправлена подпись доминантсептаккорда в обращении.

## Автоматические проверки

- JVM: 8 тестов, включая 90 720 комбинаций музыкальной теории, точные pitch classes, обращения, приоритет клавиш, меню, джойстик, отмену STRUM и остановку ARP/DRONE.
- C++: тестируется тот же SynthCore, что включён в APK. Все восемь пресетов на 44.1/48/96/192 kHz; ненулевой конечный сигнал, лимитер, переходы, затухание, переполнение и конкурентные producers. Локально выполнено на Windows/Clang, PASS.
- CI отдельно запускает этот C++ тест под ThreadSanitizer.
- Android instrumentation: реальный экран Compose, две клавиши, аккорд + джойстик, ACTION_CANCEL, старт/перезапуск настоящего Oboe. Запуск: `./gradlew connectedDebugAndroidTest`. В CI используется Android 34 x86_64 с KVM.

## Практические ограничения

Debug APK подписан отладочным ключом. Ключ локальной сборки и GitHub CI может различаться; для переустановки такой сборки потребуется удалить предыдущую.

Локальные JVM/DSP проверки не подтверждают слышимый звук через динамик, реальную задержку касание→звук, Bluetooth/USB маршрутизацию или отключение наушников на телефоне. Эти проверки требуют Android-устройства. Локально ADB не обнаружил устройств, а ускоритель эмулятора не установлен. Состояние Android-тестов и CI следует смотреть в соответствующем запуске Actions.

Значение latency — оценка Oboe/размера burst, а не гарантированная полная задержка. Зависимости Stage A сохранены; lint сообщает о доступных обновлениях. Этап B не начат.
